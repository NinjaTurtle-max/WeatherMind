## 4. 콘텐츠 갭 정량화

- 커리큘럼 유닛 5개 / 개념 태그 6종 — Duolingo 단일 코스 대비 ×10 이상 격차.
- 첫날 문항 중복 4/9 — 0이어야 정상. **지금 병목은 엔진이 아니라 뱅크다.** 보드 규칙 8종·단면 스토리보드 8종 등 구조는 콘텐츠보다 앞서 있으므로, R10부터 저작·생성 파이프라인에 리소스를 이동한다.

## 5. 방법론 한계

mock 배합(세션 9문항, 시드된 Lv.4/스트릭 6)은 계약값(5문항)과 다르나, 에너지 소진·문항 반복은 mock/실서버 공통 로직에서 발생하므로 발견은 유효. Duolingo는 게스트 구간만 관찰(리그·상점·유료 제외). 본 문서는 내부 벤치마킹 전용 — 메커니즘 비교만 다루며 대외 문서에서 벤치마킹 대상 언급 금지 원칙 유지.
