#### 3.2-2 잠긴 기능 화면 — **우리 설계와 정반대다**

  ③ 가치 제안 ④ 해제 조건(진행형) ⑤ **해제로 가는 행동 CTA**를 놓는다.

  잠금 해제됩니다", "더 많은 퀘스트가 곧 잠금 해제됩니다" — 잠금을 기대감으로 전환).

## 5. 방법론 한계

mock 배합(세션 9문항, 시드된 Lv.4/스트릭 6)은 계약값(5문항)과 다르나, 에너지 소진·문항 반복은 mock/실서버 공통 로직에서 발생하므로 발견은 유효. Duolingo는 게스트로 관찰(유료 결제·실제 리더보드 경쟁 제외); 레슨 완료 보상 화면은 게스트 진도 미저장 + 캔버스 보드의 자동화 제약으로 미도달. 본 문서는 내부 벤치마킹 전용 — 메커니즘 비교만 다루며 대외 문서에서 벤치마킹 대상 언급 금지 원칙 유지.
