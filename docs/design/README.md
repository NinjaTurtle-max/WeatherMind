# 디자인 시안 (docs/design)

구현 전에 합의한 화면 시안을 둔다. **시안은 계약이 아니라 제안**이다 — 수치가
코드와 어긋나면 코드가 SSOT다. 다만 아래 「검증된 동작 계약」만은 시안이 먼저
정하고 구현이 따라간다(요구사항이 동작이라 그림으로는 표현되지 않기 때문).

## learn_session_mockup.html — 학습 세션 화면

브라우저로 바로 열면 된다(빌드·의존 없음). PC(md↑) 기준 시안이다.

### 무엇이 확정됐나

- **캐릭터 6종이 들어왔다**(2026-08-04). `frontend/public/`의 ASCII 파일명 —
  `cloud`(메인 튜터) · `sun`(학습 세션) · `drop`(보드) · `bolt`(퀴즈·즉각 피드백) ·
  `typhoon`(리그) · `snow`(예보 대결). 이전 마스코트 「썬더」와 한글 파일명 png는
  전부 제거했다. 화면에서 참조할 때는 경로를 직접 쓰지 말고
  `components/Mascot.jsx`를 거친다 — 캐릭터 교체 지점을 한 곳으로 모으기 위함이다.
- UI 크롬은 앱 원래 파란색(`sky-600 #0284C7` 계열). 주황은 태양이 본체에만 쓴다.
- 단계 구성은 `database/seed/units.json`을 그대로 따른다 — 4섹션 12유닛
  (하늘 읽기 3 · 공기의 힘 3 · 큰 바람 2 · 도시와 기후 4). 유닛명·`concept_tag`·
  `kind:"board"` 표식(🧩)까지 시드와 일치시켰다.
- **경로는 흰 배경 위 세로 지그재그**다(2026-08-04 최종). 자연 배경·기상 기호는
  전부 걷어냈다 — 배경 없이 길과 노드만 남긴다. 개념어는 하단
  「이 단계에서 배우는 것」 스트립에만 둔다.
  (중간에 섹션별 자연 배경안이 있었으나 폐기했다. 히스토리는 이 파일의 git log 참조.)
- 섹션 보상 상자도 **길 위의 한 칸**이다 — 옆에 붙은 카드가 아니다.
- **노드 밑에 라벨을 두지 않는다**(2026-08-04). 아이콘만 크게 두고 유닛명은
  `title`/`aria-label`로 남겨 호버·스크린리더에서 확인한다. 현재 유닛명은 트랙
  하단 진도 바가, 단계 요약은 「이 단계에서 배우는 것」 스트립이 이미 보여준다.

### 검증된 동작 계약 (구현 시 반드시 유지)

사용자 요구가 "고정된 주변 패널 + 학습 트랙만 스크롤"이라, 이건 그림이 아니라
동작이다. 시안에서 5개 해상도(1024·1280·1440·1600·1920)로 실측해 통과시켰다.

| 계약 | 측정 방법 | 기대값 |
|---|---|---|
| 페이지 자체는 스크롤되지 않는다 | `documentElement.scrollHeight - clientHeight` | 0 |
| 가로 스크롤 없음 | `scrollWidth - clientWidth` | 0 |
| 스크롤바 비표시 | `scroller.offsetWidth - clientWidth` | 0 |
| 트랙 위에서만 휠이 먹는다 | 좌측 내비 위 휠 → `scroller.scrollTop` 불변 | 불변 |
| 한 화면에 한 단계 | 스냅 지점마다 보이는 `.stage` 수 | 정확히 1 |

구현에서 밟기 쉬운 함정 세 가지(시안에서 실제로 밟았다):

1. **그리드 칸의 `min-height:auto`** — 세 칸(내비·본문·레일) 모두 `min-height:0`
   으로 눌러야 한다. 안 그러면 본문이 내용만큼 늘어나 셸을 밀어내고 페이지가
   같이 스크롤된다(시안 초기값에서 170px 밀렸다).
2. **`overscroll-behavior:contain`** — 트랙 끝에서 페이지로 스크롤이 전파되는 걸
   막는다. 이게 없으면 "주변은 고정" 요구가 트랙 끝에서 깨진다.
3. **한글 `word-break`** — 기본값은 글자 단위로 끊어서 "태어나는 / 가"가 된다.
   유닛명에는 `word-break:keep-all`이 필요하다.

### 세로 경로에서 지키는 것

- **노드 좌표를 상수로 박지 않는다.** 섹션마다 노드 수가 3·3·2·4(+보상)로 달라
  손으로 찍으면 리듬이 어긋난다. 가로 흔들림은 노드 인덱스 사인으로 구하고,
  연결선은 렌더 후 실측 좌표로 그린다(리사이즈 시 다시 그린다).
- **길은 스냅 경계를 넘어 이어진다.** 각 단계의 첫·끝 노드에서 이웃 단계의 끝
  노드 쪽으로 선을 뻗어, 한 화면 한 단계로 스냅되면서도 하나의 길로 보이게 한다.
- **`translateX(%)`를 쓰지 말 것.** 백분율이 컨테이너가 아니라 자기 자신의 폭
  기준이라 지그재그가 거의 움직이지 않는다(실제로 밟았다). px 진폭을 곱한다.
- **보상 상자도 노드다.** 진도 판정용 유닛 인덱스와 위빙용 노드 인덱스를 따로
  세지 않으면 보상 칸이 "현재 유닛"이 된다(실제로 밟았다).
- **연결선 SVG는 `position:absolute`**라 위치 없는 형제(헤더·정보 스트립) 위로
  그려진다. 그 둘에 스태킹을 줘서 선이 뒤로 가게 한다.
- **노드 크기는 세로 공간이 정한다.** 가장 빡빡한 곳은 5칸이 들어가는 도시와
  기후다. `--dot` 하나로 조절하고 `max-height` 미디어쿼리로 86 → 74 → 66px까지
  줄인다. 실측 기준은 "5칸 섹션에서 노드 간격 ≥ 19px, 넘침 0".

### 아직 자리표시인 것

- 포즈가 캐릭터당 1종뿐이다. 정답/오답으로 표정을 바꾸려면 포즈가 더 필요하다
  — 지금은 피드백 패널이 같은 그림을 쓰고 정오답은 배지·문구로만 구분한다.
- 튜터 대사 — 사전형 기상 용어로 채우기로 했으나 내용 미확정
- 우측 레일의 수치(학습 시간·배지)는 대응 API가 없어 시안 값이다.
  진도(3/12)·유닛 완료 수는 시드 기준으로 앞뒤를 맞춰 뒀다.
