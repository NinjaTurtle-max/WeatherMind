# 문의 — 로그인 방식 및 배포·제출 관련

**팀명**: (기재)
**서비스명**: WeatherMind — 날씨 데이터 기반 기후 학습 서비스
**문의일**: 2026-08-19

---

## 1. 로그인 방식

### 1-1. 현재 구현 방식
- 기본 진입: **로그인 없이 즉시 이용** (게스트 자동 발급)
- 게스트 상태에서 **전 기능 이용 가능** — 학습·퀴즈·보드 퍼즐·예보 대결·리그 참여 포함
- 로그인은 **선택 사항**, 용도는 **다른 기기로 학습 진도 이전** 하나뿐
- 게스트 식별: 시스템이 자동 부여(예: `게스트-a1b2c3`), 이용자 입력 불요

### 1-2. 질의 사항
- ① 위 방식이 「로그인 없이 열려야 함」 요건에 **부합하는지**
- ② 로그인 기능의 **존재 자체**가 감점 요인인지, 아니면 **강제 여부**만 판단 기준인지
- ③ 심사위원이 심사 시 **로그인 화면을 전혀 거치지 않음**을 어떻게 증빙해야 하는지
  - 예: 시연 영상 · README 명시 · 별도 안내문 등
- ④ 진도 이전을 위해 **이메일·비밀번호를 수집**하는 것이 개인정보 관련 요건에 저촉되는지
  - 저장 항목: 이메일, 비밀번호(해시), 닉네임
  - 수집 시점: 이용자가 「진도 저장」을 직접 선택한 경우에 한함
- ⑤ 대안으로 **닉네임만으로 진도 조회**하는 방식도 검토했으나, 타인의 닉네임 입력으로 진도 열람이 가능해 **보안상 부적절**하다고 판단 — 이 판단이 타당한지

## 2. 배포 방식

### 2-1. 현재 구성
- 클라우드 VM 1대에 컨테이너로 배포
- 접속 주소: **IP 기반 도메인 서비스**(sslip.io) 사용 — 예: `https://34-47-71-146.sslip.io`
- 고정 IP 예약 완료 — 서버 재기동에도 주소 불변
- HTTPS 적용

### 2-2. 질의 사항
- ① **IP 기반 도메인**(sslip.io 등) 사용이 허용되는지
  - 별도 도메인 구매·연결이 **필수 요건**인지
- ② **HTTPS 인증서** 요건 유무 — 자동 발급 인증서로 충분한지
- ③ URL 유지 기간(9월 셋째 주까지) 중
  - **무중단 가동**이 요건인지, **접속 가능 상태 유지**면 되는지
  - 기간 중 **서버 재기동·점검**이 허용되는지
- ④ 유지 기간 중 **서버 비용 문제로 사양 축소**가 필요할 경우 허용 범위

## 3. 제출·동결 관련

### 3-1. 질의 사항
- ① 제출물(구글 폼 업로드 4종)과 **구동 URL**의 관계
  - URL이 제출물에 포함되는지, 별도 기재인지
- ② **동결 시점(8/21 18:00)**의 기준
  - **배포 기준**인지 **소스 커밋 기준**인지
  - 동결 이후 **장애 대응 목적의 수정**이 허용되는지
- ③ 제출물 중 「프롬프트 세션」의 **범위·형식**
  - 전체 대화 기록인지, 주요 부분 발췌인지
  - 파일 형식 지정 여부
- ④ **API 키 미포함** 상태로 제출 시, 심사 과정에서 해당 기능이 **동작하지 않는 것**에
  대한 감점 여부
  - 해당 기능: 생성형 AI 기반 문항 생성·해설
  - 현재 조치: 키 없이도 **사전 저작 문항으로 전 기능 동작**하도록 구현
