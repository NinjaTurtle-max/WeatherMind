## 2. ✅ IN — 내일 롤링에 넣는다 (신규 2건)

### ⑬ 탐구 조작 변수 보강 — **최우선**

**배점 근거**: 체험·참여형 10점 항목 원문이 *"변수를 바꿔가며 학습 탐구가 가능한가"*.

**실측**: 화면은 전부 있는데 **변수가 얇다**.

| 화면 | 현재 조작 변수 |
|---|---|
| 태풍 | 슬라이더 1(해수면온도) + 시어 선택 1 = **2** |
| 기후변화 | **1** |
| 위성 | **1** |
| 자유 보드 | 보드 자체 상호작용(슬라이더 아님) |

**할 일**: 기후변화에 2변수, 태풍에 1변수 추가. 값→결과가 **즉시 화면에 보이는** 것만.
**소유** A조(⑪-b 뒤) · **반나절** · 엔진 확장 불요(기존 파생식에 입력만 추가)

### ⑭ 산불 모식도 개선

**배점 근거**: 독창성 8점 항목 원문이 *"산불-홍수 모식도"* **쌍**인데 홍수만 끝났다.

**대상 2장**: `wildfire_risk_dry_gale` · `siberian_gale_wildfire`
**할 일**: 홍수에서 확립한 패턴 그대로 — **깊이/규모를 잴 물건**(홍수의 차 = 산불의 수관·건물)
+ 지형 층화 + 오독 차단(화선이 바람 방향과 어긋나 보이지 않게).
**소유** PM · **반나절** · 조사 문서 동봉(홍수와 동일 절차 — 복제·트레이싱 금지)
