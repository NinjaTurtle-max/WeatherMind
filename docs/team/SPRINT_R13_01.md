## 2. 계약 (완료 판정 = 기계 검증)

### 2.1 만회 라운드 (BE-1 · FE-1 — 임계 경로)

- **데이터**: `quiz_logs.retry_correct BOOLEAN NULL`(마이그레이션 **0011**, downgrade 필수).
  원래 `is_correct`는 **불변 보존** — 최초 정오 기록은 θ·통계의 근거라 덮으면 안 된다.
- **서버**: 답안 라우터에 만회 경로 — 이미 답한 문항(`already_answered`)이고
  `is_correct=false`이며 **같은 세션**일 때만 재제출 허용, 결과를 `retry_correct`에 기록.
  그 밖의 재제출은 현행 멱등 의미론 유지(409 아님·기존 결과 반환).
  **구름 무소모**(만회는 벌이 아니다) · XP 무가산(최초 정답만 XP — 파밍 차단).
- **왕관 정책**: `all_correct` → `all_resolved = 전 문항이 (is_correct=true) 또는
  (retry_correct=true)`. 세션 최초 완료 조건은 유지.
- **프론트**: 세션 마지막 문항 뒤 오답 문항을 큐에 재투입, 완료 화면에 "만회 완료" 표기.
- **검증**: 만회 성공→왕관 부여 / 만회 실패→왕관 없음 / 최초 정답 문항 재제출 불가 /
  `is_correct` 불변 / 구름 무소모 — 5건 계약 테스트 + 스모크 3시나리오.

### 2.2 전문가 밴드 (BE-2)

`expert`를 4번째 학령으로 추가. 파급 지점 실측 목록(전부 값 추가만, 스키마 무변경):
`seed_content.ALLOWED_LEVEL_GROUPS` · `priors.LEVEL_GROUP_PRIORS`·`LEVEL_GROUP_ITEM_B` ·
`weatherbrain_service.theta_to_level_group`의 버킷 튜플 · `theta_level_label` 경계 ·
프론트 `abilityDisplay` 라벨 + i18n 키. **경계값은 backend↔ai-worker 동일**해야 하고
기존 계약 테스트가 그것을 감시한다 — 한쪽만 바꾸면 실패한다.

### 2.3 금칙 용어 규칙 (CT-1)

`lint_seed_items.py`에 학령별 금칙 어휘 검사 추가. 목록은 `database/seed/
level_vocabulary.json`(신규)이 소유 — 코드에 박지 않는다. elementary·middle_high에서
전공 용어(권층운·권운·고층운·난층운·건조단열·지균풍 등) 사용 시 **탈락**.
adult·expert는 허용. 기존 141문항 중 위반분은 CT-1이 재저작한다.

### 2.4 재난 축 1차 개통 (BE-2 · CT-2 · CT-3)

- 개념 태그 2종 신설: `wildfire_weather`(산불 기상 — 건조·강풍·실효습도)
  `flood_response`(홍수 대응 — 호우 강도·행동 요령). **지진은 범위 밖 확정**(지질학).
- 보드는 기존 판정 규칙 재사용(신규 규칙 저작 금지 — 엔진 무변경). "위험 기상 생성
  보드 → 행동 요령 ordering" 연쇄 유닛으로 구성.
- 행동 요령은 **순서가 유일한 것만** 채택(채점 방어 — R12 §9 판단 준용).

### 2.5 진입 통합 (FE-2)

홈의 학습 진입을 카드 1개로. 우선순위: 진행 중 유닛 → 오늘 미발급 일일 세션 →
완료 축하. 자유 일일 세션은 보조 링크로 강등. `nav` 탭 수 단정(스모크) 불변.

### 2.6 교사 캐릭터 (FE-2)

보드 힌트·오답 피드백에 기존 마스코트 자산(표정 6종) 말풍선 배치. 힌트 단계에 따라
표정 전환. **문구 자체는 불변**(기존 스모크가 한국어 원문을 단정 — 표현 바꾸면 회귀).

### 2.7 시뮬 생동감 (FE-3)

`requestAnimationFrame` + canvas로 태풍 소용돌이(해수온 실시간 반응)·기후 타임랩스.
`prefers-reduced-motion` 준수 필수. **3D는 범위 밖 명시**.

### 2.8 분반 리더보드 (BE-2 · FE-3)

주간 리더보드를 소집단(기본 30인)으로 분할 + 내 순위 이웃 격차 표시.
친구·팔로우는 **범위 밖 명시**(모델 신설 불가).
